# Arizona State University (ASU): official starting points

A head start for students whose school domain is asu.edu. Open each page to confirm the details before replying.
Perks, prices and eligibility change every term, so the short notes below say where to look, not what to
promise. Last reviewed 2026-10-24.

## Software and AI

| What | Official page | Note to confirm on the page |
| --- | --- | --- |
| ASU-approved AI tools catalog | https://ai.asu.edu/ai-tools | Who can use each tool and how to start |
| ChatGPT Edu | https://ai.asu.edu/chatgpt-edu | Provided through ASU's agreement with OpenAI |
| Adobe Express and Firefly | https://ai.asu.edu/adobe-express-firefly | Listed as free for ASU students |
| Adobe at ASU (Creative Cloud access) | https://uto.asu.edu/adobe | How students request access |
| Microsoft 365 (Office) | https://uto.asu.edu/node/515 | For currently enrolled students |
| ASU Enterprise Technology (software, Zoom, more) | https://uto.asu.edu | Search here for any other app before the student pays |

When a student is about to buy an AI or coding tool, check the AI tools catalog first: ASU may already give
them an equal tool. Fulton Schools of Engineering also keeps an AI resources page for its students.

## If something isn't listed

Run `python3 scripts/school.py show --domain asu.edu --query "<item>"` and open the ASU pages its searches
find. Count a perk only if an ASU page says students get it, then save it with `school.py add`.
